## Material limits

Kafka source commit uncertainty, AMQP lost confirmations and ClickHouse lost
responses retain at-least-once replay/duplicate windows. UDP traps remain
unreplayable. Legacy SNMPv3 trap receive now fails explicitly because it never
provided authentication/privacy; the default stack is required for that path.

The SNMP pilot evidence uses isolated loopback responders and real SFTP
readback. It establishes the recorded local pilot, not production fleet capacity.
The original PGW ASN.1 benchmark inputs remain unavailable. Plain repository
Ruff currently includes unrelated untracked artifact scripts with existing
errors; scoped lint does not count as a green mandatory release gate.

[independent review](v1.8.3-full-diff-independent-review.md) for test snapshots,
reproductions and remaining acceptance boundaries.
